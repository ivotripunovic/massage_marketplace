# PRD Prompt for Claude AI - Massage Service Marketplace

```
Create a Product Requirements Document (PRD) for a massage service marketplace 
with the following specifications:

## Business Model
- Revenue: Monthly subscription fee charged to service providers
- Payment: Cryptocurrency Bitcoin, Ethereum, USDC, and bank transfers
- bank transfers are verified manualy 
- Free for clients
- Minimum viable product (MVP) approach - only essential features for fastest time to market

## Minimum Core Features

### Provider Portal:
- Account creation and profile (name, bio, photo, certifications)
- Contact details phone number
- Create/edit service listings (service type, price, duration)
- Crypto wallet integration for subscription payments
- Monthly subscription management (active/inactive status)

### Client App:
- Browse available providers
- Search/filter by:
  * Service type
  * Location Country, City with map-based
  * Price range
- View provider profile and reviews
- Rate/review provider after service

### Admin Dashboard (Internal):
- Manage provider subscriptions and payments
- Monitor disputes or issues
- Basic analytics

## Out of Scope (Future):
- In-app messaging (email/phone contact instead)
- Advanced analytics
- Mobile app (responsive web first)
- Complex verification system

## Technical Notes:
- Crypto integration for monthly subscription billing
- Handle failed payments and subscription renewal
- as little javascript, no javascript frontend

Please structure as: Overview, Business Model, Core User Stories, 
Minimum Features, Technical Architecture, Success Metrics, and 3-month Timeline.
```
